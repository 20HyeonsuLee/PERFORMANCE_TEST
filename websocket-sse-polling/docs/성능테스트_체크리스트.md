## 참고사항

### 현재 코드 상태
- WebSocketService: 브로드캐스트 로직 미구현 (주석만 존재)
- SseController: 수동 브로드캐스트만 가능, 자동 반복 전송 미구현
- BroadcastConfig: delay, tps, duration 파라미터 정의됨

### 테스트 시 고려사항
- 각 테스트 간 충분한 쿨다운 시간 (서버 리소스 안정화)
- JVM Warm-up (최소 10초)
- 동일한 하드웨어 환경에서 테스트
- 네트워크 환경 일관성 유지
- 백그라운드 프로세스 최소화
